# SHOWTELA CORE REBOOT v0.1

Status: CANONICAL

## Mission

Build the smallest possible ShowTELA that proves operational value.

The goal is not continuity.
The goal is not governance.
The goal is not orchestration.

The goal is:

UPLOAD → EXTRACT → HYDRATE → ANSWER → EVIDENCE

# Live Operations UX Skill

## Purpose

Teach Codex to think like live production staff instead of generic SaaS UX.

## Assume The User May Be

- backstage
- on headset
- walking
- stressed
- in darkness
- under time pressure
- working with one hand
- switching between people, spaces, and tasks

## Optimize For

- one-thumb interaction
- immediate comprehension
- glanceability
- low cognitive load
- large touch targets
- operational urgency visibility
- fast next-step recognition

## Avoid

- deep menus
- excessive typing
- hidden actions
- dashboard clutter
- unclear statuses
- tiny controls

## Operating Rule

If the interface would struggle under backstage pressure, it is not finished.

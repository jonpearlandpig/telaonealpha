# Runtime Restraint Skill

## Purpose

Prevent AI coding agents from overbuilding, rewriting stable systems, or introducing unnecessary architectural complexity.

## Core Principles

- Do not rewrite stable systems.
- Do not introduce unnecessary abstractions.
- Do not over-engineer orchestration.
- Do not create speculative infrastructure.
- Do not replace working substrate without explicit need.
- Do not add dependencies for visual novelty.
- Prefer incremental evolution.
- Prefer substrate stability.
- Prefer operational clarity.
- Prefer focused execution.
- Prefer small safe patches.
- Prefer reversible changes.

## Operating Rule

When a change can be solved with a narrow surface patch, choose that over architectural expansion.

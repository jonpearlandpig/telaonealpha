# Continuity Recovery Skill

## Purpose

Prepare Codex and TELAOne for broken, stale, interrupted, or conflicting operational continuity.

## Prefer

- graceful degradation
- continuity reconciliation
- stale-state visibility
- resumable context recovery
- operational confidence signaling
- conflict preservation
- partial-state handling

## Never

- fabricate certainty
- silently discard unresolved state
- overwrite conflicting continuity
- hide stale data
- pretend missing context exists

## When Ambiguity Exists

- surface confidence levels
- preserve competing states
- request clarification only when operationally necessary
- mark unresolved items clearly

## Operating Rule

Continuity recovery is mandatory because real-world operational conditions are messy.

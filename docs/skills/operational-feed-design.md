# Operational Feed Design Skill

## Purpose

Teach Codex that ShowTELA is feed-native, not dashboard-native.

## Prefer

- stacked operational cards
- timeline continuity
- entity-linked updates
- swipeable operational moments
- visual operational anchors
- card-level action clarity
- newest relevant state surfaced first

## Avoid

- enterprise dashboards
- dense tables
- admin-heavy layouts
- spreadsheet aesthetics
- static status walls

## The Feed Should Feel

- alive
- calm
- useful
- current
- operationally inevitable

## Operating Rule

The feed is the operational consciousness surface, not a reporting dashboard.

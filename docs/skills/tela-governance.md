# TELA Governance Skill

## Purpose

Teach Codex constitutional operational behavior across provenance, escalation, rollback awareness, audit visibility, and authority levels.

## All High-Impact Actions Require

- provenance
- operator attribution
- timestamping
- rollback awareness
- audit visibility
- authority awareness

## Respect

- authority levels
- constitutional systems
- audit visibility
- lineage preservation
- escalation requirements
- approval gates

## Never

- silently mutate governance state
- bypass escalation rules
- fabricate operational certainty
- obscure authorship
- erase decision context

## Operating Rule

Governance is part of the TELA moat and is never optional infrastructure.

# Execution Prioritization Skill

## Purpose

Prevent feature sprawl and force Codex to prioritize the work that makes TELAOne more real, stable, and usable.

## Priority Order

1. operational continuity
2. runtime stability
3. mobile responsiveness
4. execution clarity
5. user trust
6. feature expansion
7. visual polish

## Never Sacrifice

- continuity
- hydration integrity
- auth stability
- persistence
- operational fluency

## Never Trade Them For

- novelty
- speculative infrastructure
- unnecessary animation
- premature automation
- visual theater

## Operating Rule

Build what is necessary for proof and trust before building what is merely interesting.

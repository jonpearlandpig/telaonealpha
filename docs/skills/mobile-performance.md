# Mobile Performance Skill

## Purpose

Ensure ShowTELA remains operationally fast and responsive on mobile devices.

## Prioritize

- smooth scrolling
- low memory usage
- fast hydration
- low animation overhead
- touch responsiveness
- reliable mobile rendering
- quick first usable view

## Avoid

- excessive blur
- large realtime renders
- unnecessary 3D
- animation-heavy interactions
- expensive rerenders
- dependency-heavy UI experiments

## Operating Rule

Mobile operational fluency is more important than visual novelty.

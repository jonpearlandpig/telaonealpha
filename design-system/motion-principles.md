# Motion Principles

## Doctrine
- Use restrained motion to reinforce meaning.
- Favor slow-in fast-out timing for composure.
- Use soft spring physics with minimal bounce.
- Apply subtle parallax only when it clarifies hierarchy.
- Build hierarchy through motion, never decoration.

## Avoid
- flashy animation
- gimmicks
- excessive movement

## Desired Feel
Motion should feel premium, deliberate, expensive, and cinematic.

# Runtime Provider Routing

## Routing Principles
- Provider abstraction is mandatory.
- Model replaceability is required for sovereign runtime control.
- Sovereign orchestration determines routing policy.
- Routing discipline must not leak provider-specific identity into core continuity systems.

# TELAOne AKB Model

## Retrieval Doctrine
TELAOne uses entity-first retrieval with provenance-aware memory and continuity snapshots.

## Core Capabilities
- Entity-first retrieval
- Provenance-aware memory
- Continuity snapshots
- Thread restoration
- Relationship reconstruction
- Operational memory ranking

## AKB Retrieval Priority
1. active operational context
2. continuity relevance
3. entity relationship density
4. authority confidence
5. temporal proximity
6. provenance trust

## Explicit Retrieval Scope
TELA retrieves:
- continuity
- lineage
- unresolved operational state
- memory relationships

TELA does **not** retrieve:
- flat documents only

## Runtime Identity
The runtime is continuity-first, memory-aware, operationally calm, lineage-preserving, and cognitively persistent.

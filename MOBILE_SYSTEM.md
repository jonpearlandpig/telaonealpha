# TELAOne Mobile System

## Primary Viewport
- **393px width is the primary design viewport.**

## Mobile-First Rules
- Mobile-first always.
- Desktop adapts from mobile, never the inverse.
- Thumb ergonomics first for all primary actions.
- Swipe-native interaction is preferred for sequence and navigation.
- Momentum scrolling should feel natural and stable.
- Snap alignment should reinforce rhythm and orientation.
- Large tap surfaces are mandatory.
- Editorial spacing supports calm hierarchy.
- Visual hierarchy must remain operationally calm.

## Runtime Alignment
- Mobile layouts must preserve continuity visibility.
- Entity and lineage cues must remain readable at handheld scale.
- Interaction density must not compromise cognitive persistence.

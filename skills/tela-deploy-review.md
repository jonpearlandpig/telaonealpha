# TELA Deployment Review Skill

## Evaluation Criteria
- deployment configuration continuity
- no dependency duplication
- shell and route stability
- operational identity preservation
- local-first survivability posture

## Rejection Criteria
- deployment strategy drift
- Vercel configuration mutation without governance approval
- dependency churn that destabilizes runtime
- route or shell regressions tied to release packaging

## Completion Criteria
- deployment settings remain stable
- build and lint validations pass
- no config drift is detected
- runtime governance constraints remain intact

## Regression Warnings
- silent deployment config edits
- indirect dependency bloat
- release pipeline changes bypassing governance chain

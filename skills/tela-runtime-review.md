# TELA Runtime Review Skill

## Evaluation Criteria
- continuity visibility
- entity-first retrieval alignment
- provenance-aware memory behavior
- provider abstraction integrity
- modular consistency
- operational calm under runtime transitions

## Rejection Criteria
- chat-first or CRUD-first architectural drift
- provider-coupled core runtime logic
- missing provenance trails
- unresolved state loss between sessions

## Completion Criteria
- continuity snapshots are restorable
- retrieval ranking reflects entity and provenance priorities
- provider routing remains replaceable
- runtime behavior preserves cognitive persistence

## Regression Warnings
- recency-only retrieval bias
- continuity snapshot erosion
- hidden provider assumptions in orchestration

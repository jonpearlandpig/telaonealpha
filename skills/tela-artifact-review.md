# TELA Artifact Review Skill

## Evaluation Criteria
- artifact materialization quality
- continuity linkage
- lineage visibility
- provenance integrity
- preview and download readiness
- grouping by thread

## Rejection Criteria
- artifact fallback to chat blobs
- missing lineage or authority metadata
- non-previewable or non-downloadable outputs
- fenced code/html shown when extraction succeeded

## Completion Criteria
- artifacts behave as runtime objects
- lineage and provenance are inspectable
- render-first behavior is consistent
- thread grouping is preserved

## Regression Warnings
- artifact metadata erosion
- UI fallback that hides extractable outputs
- weak continuity linkage across revisions

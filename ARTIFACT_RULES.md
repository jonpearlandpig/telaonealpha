# TELAOne Artifact Rules

## Artifact Identity
Artifacts are **not**:
- chat blobs
- fenced code dumps
- temporary UI fragments

Artifacts are:
- runtime objects
- continuity-linked outputs
- lineage-preserving operational assets

## Artifact Behavior Rules
- Artifacts must be downloadable.
- Artifacts must be previewable.
- Artifacts must be continuity-aware.
- Artifacts must be provenance-linked.
- Artifacts must be grouped by thread.
- Artifacts must be render-first.

## Assistant Rendering Rule
Suppress fenced code/HTML inside assistant bubbles whenever extraction succeeds, and materialize extractable outputs as first-class artifacts.

## Governance Alignment
Every artifact must retain lineage references, authority context, and retrieval relevance for continuity restoration.
